## About

I design and ship **LLM-powered products** — from tool-calling agents that reason over
personal finance, to study copilots that turn raw notes into personalised learning
systems. I care about taking AI projects past the demo stage: clean architecture,
measurable output, and a UI people actually want to use.

- **Now** — building [FinHelper](https://github.com/ap1807/FinHelper), [AI-Exam-Coach](https://github.com/ap1807/AI-Exam-Coach) and [finrisk-sentinel](https://github.com/ap1807/finrisk-sentinel)
- **Focus** — LangChain · RAG pipelines · tool-calling agents · prompt evaluation
- **Stack** — Python, TypeScript, Streamlit, Django, Next.js
- **Basis** — CSE @ Lovely Professional University, Phagwara (PB), India
